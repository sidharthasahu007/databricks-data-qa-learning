# Datasets

This folder contains the sample datasets used throughout this Databricks Data QA learning project.

## Purpose
Storing the raw CSV/JSON files here ensures the project is fully reproducible. Anyone reviewing this repository can download the datasets and run the notebooks and scripts exactly as intended.

## Contents
- **Retail Sales Dataset** – Used for ingestion, Delta Lake conversion, and validation examples.
- **Customer Segmentation Dataset** – Used for SQL and PySpark validation exercises.
- **Product Catalog Dataset** – Used for referential integrity checks and Bronze → Silver → Gold pipeline demonstrations.

## Notes
- All datasets are small, public, and safe to share.
- These files are used only for learning and demonstration purposes.
- If a dataset is large, consider uploading a sample instead.
