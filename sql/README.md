This folder contains SQL queries used for data validation, profiling, and reconciliation within the Databricks Data QA Learning Project.
SQL plays a critical role in data QA because it provides fast, declarative checks that are easy to understand, audit, and maintain.

These scripts demonstrate how SQL is used alongside Python and PySpark to validate data across Bronze, Silver, and Gold layers.

**Purpose of This Folder**

The sql/ directory stores:

    validation queries

    profiling queries

    reconciliation logic

    schema inspection queries

    business rule checks

Keeping SQL scripts separate from notebooks makes the project modular and easier to maintain.
